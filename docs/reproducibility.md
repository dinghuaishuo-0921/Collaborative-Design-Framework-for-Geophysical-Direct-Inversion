# Reproducibility Summary

The repository provides three distinct levels of use.

| Level | Command | Data requirement | Purpose |
| --- | --- | --- | --- |
| Format check | `python examples/quick_test.py` | None | Verifies the MAT layout and structured-output constraints. |
| Smoke training | `python src/run_architecture_benchmark.py --config ../configs/quick_benchmark_example.json --smoke` | Synthetic data generated by the quick test | Verifies TensorFlow training and report generation. |
| Full protocol | See `docs/experiment_guide.md` | Mendeley MAT dataset plus derived datasets | Reproduces the paper-scale protocol. |

The quick check and smoke training are directly runnable. Their metrics are not
paper results. For a full reproduction, download the Mendeley MAT file into
`datasets/` and run `python src/build_paper_sampling_datasets.py` once. This
creates D1/D2/D3 and P10/P20/P30 datasets under `datasets/derived/`.

Every full experiment writes its configuration copy, point metrics, aggregate
metrics, training histories, and a Markdown report into `runs/<run-name>/`.
The compact CSV tables in `data/` are the final reported results, not model
checkpoints.
