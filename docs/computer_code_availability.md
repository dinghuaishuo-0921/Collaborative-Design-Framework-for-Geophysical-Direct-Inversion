# Computer Code Availability

The source code used for data construction, structured-output inversion,
encoder comparison, model training, and evaluation in this
study is publicly available at:

`https://github.com/dinghuaishuo-0921/Collaborative-Design-Framework-for-Geophysical-Direct-Inversion-`

The repository contains individual source files, dependency information,
documentation, manuscript result tables, a 10,000-sample training subset, and
a synthetic quick-test example. The complete forward-model training dataset is
released separately through Mendeley Data; add its DOI URL here after publication.
Field logging data are not redistributed because of data-use restrictions.
